# Project Overview

The Enterprise MECM Homelab was designed to simulate a real enterprise Windows infrastructure using Microsoft technologies.

The primary objective was to gain practical experience deploying, configuring, documenting, and troubleshooting technologies commonly used by System Administrators and Cloud Infrastructure Engineers.

The project evolved from a simple virtualization lab into a complete enterprise management environment capable of supporting centralized device administration.

---

# Original Goals

The project began with the following objectives:

* Learn Microsoft Hyper-V
* Build an Active Directory domain
* Deploy enterprise networking services
* Learn Microsoft Configuration Manager
* Improve PowerShell skills
* Document every deployment step
* Publish the project on GitHub

All of these goals were achieved or are actively progressing.

# Technical Challenges

Several technical challenges were encountered throughout the project.

Examples include:

* SQL configuration
* MECM prerequisites
* Client Push failures
* DNS troubleshooting
* Boundary Groups
* RRAS configuration
* Hyper-V networking
* BITS download failures
* Windows Firewall configuration
* Administrative share access

Each issue required structured troubleshooting and reinforced the importance of validating every infrastructure layer.

# What Went Well

Several design decisions significantly improved the project.

* Separating internal and external networks
* Using RRAS for NAT
* Centralizing services on DC01
* Maintaining structured documentation
* Capturing screenshots throughout the deployment
* Tracking changes using GitHub
